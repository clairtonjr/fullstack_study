Hiperlinks

Hiperlinks são formas de vincular documentos com outros documentos. Também podemos vincular - ligar, linkar - partes específicas de documentos.

Link que vai para o página inicial do google.

adiciando mais informações no link a página inicial da Mozilla.

Para entender links é bom conhecer URL e caminhos de arquivos. URL é simplesmente uma sequência de texto que define onde algo está localizado na web. Os URL usam caminhos para encontrar arquivos. Ao trabalhar localmente com um site, teremos um diretório no qual ele todo esta dentro, podemos precisar de arquivos dentro do mesmo diretório ou fora.
