Intro

HTML é uma linguagem de marcação usada para estruturar páginas web. HTML tem diversos elementos usados para marcar diversos partes do conteúdo como links, negritos, imagens, etc.

Elementos em bloco x Elemento inline

Elementos em blocos formam um bloco visível na página, eles ocupam uma linha inteira, aparecem um abaixo do outro.

Elementos inline estão contidos dentro de elementos em blocos, envolvem apenas pequenas partes do conteúdo. Não fara que uma nova linha apareça no documento.

Exemplos:

primeiro segundo terceiro

quarto

quinto

sexto
